СПЕЦНАЗ v2.77 — кнопка принудительного обновления радара

Кнопка «ОБНОВИТЬ ЛЕНТУ» теперь выполняет прямую перезагрузку страницы
источника, открытой внутри radarSourceFrame.

Основное действие:
frame.contentWindow.location.reload()

Резерв:
повторная загрузка https://parsertgtovknews.ru/max/map.php с timestamp.

Автоматического таймера нет. Пользователь сам нажимает кнопку, когда хочет
получить свежую версию страницы источника.
