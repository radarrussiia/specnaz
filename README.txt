СПЕЦНАЗ v2.92 — обновление источника радара

Что изменено:
- В разделе «РАДАР» добавлена компактная кнопка «ОБНОВИТЬ» с круговой стрелкой.
- Нажатие обновляет только внешний источник в окне радара с новым параметром URL против кэша.
- Страница «Спецназа» целиком не перезагружается, остальные разделы и состояние собственной карты не сбрасываются.
- Сохранено автоматическое обновление источника каждые 30 секунд, когда приложение открыто и видимо.
- Обновлена версия кэша Service Worker.

Установка: распаковать архив и загрузить его содержимое в репозиторий GitHub Pages, заменив файлы сайта. Дождаться публикации и заново открыть приложение.

Примечание: кнопка повторно загружает страницу источника в iframe. Она не может заставить внешний источник показать новые сообщения, если его сервер не обновил данные или соединение недоступно.
